# CFIMEENet-U
The source code of CFIMEENet-U and the SUTD dataset
Uyghur scene images exhibit large variations in character scale and blurred text boundaries, which degrade text detection performance. To address these issues, we propose CFIMEENet-U, a Uyghur text detection model integrating cross-scale feature interaction and mul-ti-branch edge enhancement. First, to exploit Uyghur-specific character scale differences and multi-resolution text information, we con-struct a Bidirectional Cross-scale Feature Interaction Module (BCFIM). Multiple channel-spatial attention groups strengthen locally relevant features and suppress noise. Second, to alleviate blurred text boundaries caused by dots and attached strokes in Uyghur script, we introduce a Multi-branch Edge Enhancement Module (MEEM) that extracts stroke edge features at multiple scales. Finally, lever-aging the fact that Uyghur text is written along a baseline, we design a skeletonization-based Centerline-Guided Strategy (CGS) to refine text boundary localization.
